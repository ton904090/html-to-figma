# HTML to Figma

Плагін для Figma, який переносить HTML/CSS у **редаговані шари Figma**: фрейми, текст зі стилями, зображення, SVG-вектори, градієнти, тіні, рамки й радіуси.

## Чому результат точний

Плагін не намагається «вгадати» верстку, розбираючи CSS вручну. HTML рендериться **справжнім браузерним рушієм** (UI плагіна — це Chromium/WebKit), а потім знімач читає з нього готовий результат:

- геометрію кожного елемента (`getBoundingClientRect`);
- обчислені стилі (`getComputedStyle`) — кольори, градієнти, рамки, радіуси, тіні, прозорість, blend modes;
- **позицію кожного символу** тексту через `Range`, тож переноси рядків, відступи inline-елементів, інтерліньяж і базові лінії відтворюються так, як їх розклав браузер.

Далі основний потік плагіна будує з цього шари Figma і, за бажання, перетворює flex-контейнери в Auto Layout — **лише якщо** після перетворення всі дочірні елементи лишаються на своїх місцях (інакше зміна відкочується).

## Встановлення

1. Встановіть [Figma Desktop](https://www.figma.com/downloads/).
2. Зберіть плагін (або використайте вже зібрану теку `dist/` з репозиторію):
   ```bash
   npm install
   npm run build
   ```
3. У Figma: **Plugins → Development → Import plugin from manifest…** і виберіть `manifest.json` з цієї теки.
4. Запуск: **Plugins → Development → HTML to Figma**.

## Використання

1. Вставте HTML (повний документ або фрагмент разом із `<style>`), відкрийте `.html` файл або вкажіть URL.
2. Оберіть ширину вікна (1920 / 1440 / 1280 / 768 / 390, 1280×720 для слайдів або власну) — сторінка верстається саме під цю ширину, медіазапити спрацьовують.
3. Перегляньте попередній вигляд і натисніть **«Імпортувати у Figma»**. Результат з'явиться поруч з наявними об'єктами на сторінці.

### Презентації (зокрема створені в Claude)

HTML-презентації переносяться **по слайду в окремий фрейм**. Режим «Авто» сам розпізнає дек; його можна й увімкнути примусово («Що імпортувати → Презентація»).

- **Розпізнаються**: `.slide`, `section.slide`, `[data-slide]`, `.slides > section`, `.deck > section`, reveal.js (`.reveal .slides section`, включно з вертикальними стеками), remark, scroll-деки із секціями на весь екран. Якщо розмітка інша — вкажіть CSS-селектор слайдів у розширених налаштуваннях.
- **Кожен слайд знімається у своєму натуральному розмірі** (наприклад, 1280×720): масштабування `transform: scale()` / `zoom`, яким дек вписує себе у вікно, прибирається; слайд стає активним так само, як це робить сам дек (класи `active` / `current` / `present`…), анімації появи доводяться до кінця, приховані фрагменти показуються.
- Кнопки навігації, лічильник і прогрес-бар деку **не потрапляють** у слайди — знімається лише вміст слайда.
- Слайди, що займають усе вікно (`100vw × 100vh`), автоматично рендеряться у 1920×1080.
- **У дизайн-файлі** слайди розкладаються сіткою всередині секції з назвою презентації. **У Figma Slides** кожен HTML-слайд стає справжнім слайдом (масштабується до 1920×1080).

Як перенести презентацію з Claude: збережіть/завантажте артефакт як `.html` файл (або скопіюйте його код) → відкрийте плагін → вкладка «Файл» або «HTML код» → «Імпортувати N слайдів у Figma».

### Налаштування

| Опція | Що робить |
|---|---|
| **Текст: Точний** (типово) | Переноси рядків точно як у браузері (явні розриви рядків). |
| **Текст: Абзаци** | Багаторядкові абзаци стають текстовими блоками фіксованої ширини з автопереносом — зручніше редагувати. |
| **Flexbox → Auto Layout** | Flex-контейнери стають Auto Layout, якщо результат збігається з браузером із точністю до 1px. |
| **Прибрати порожні обгортки** | `div` без фону/рамки/обрізання не створюють окремого шару. |
| **Що імпортувати** | Авто / Сторінка (один фрейм) / Презентація (фрейм на кожен слайд). |
| **CSS-селектор слайдів** | Якщо слайди не розпізналися автоматично. |
| **Виконувати JavaScript** | Для сторінок і деків, що рендеряться скриптами (React, Vue, веб-компоненти). Типово скрипти вимкнено. |
| **Базовий URL** | Для відносних посилань на CSS, шрифти й зображення у вставленому HTML. |
| **CORS-проксі** | Префікс, через який завантажуються сторінки й зображення з серверів без CORS. |

## Що підтримується

- Блоки, flex, grid, float, `position` (absolute / fixed / sticky), `display: contents`, переповнення та `overflow: hidden` → `clipsContent`.
- Порядок накладання: `z-index`, контексти накладання, від'ємний `z-index` під фоном батька.
- Фони: суцільні кольори, `linear-` / `radial-` / `conic-gradient` (включно з `repeating-*`), кілька шарів, `url()` з `background-size` / `position` / `repeat`.
- Рамки з різною товщиною сторін, `dashed` / `dotted`, `outline`, радіуси для кожного кута, `box-shadow` (зовнішні та `inset`), `filter: blur / drop-shadow`, `backdrop-filter`, `opacity`, `mix-blend-mode`.
- Текст: шрифти, вага, курсив, розмір, колір, `line-height`, `letter-spacing`, `text-transform`, підкреслення/закреслення, посилання (гіперпосилання у Figma), `text-shadow`, вирівнювання, `text-overflow: ellipsis`, `pre`, sub/sup, градієнтний текст (`background-clip: text`).
- `::before` / `::after`, маркери списків (`ul`, `ol`, `details`), лічильники.
- Зображення (`<img>`, `srcset`, `object-fit`, `object-position`), WebP/AVIF конвертуються у PNG, великі зменшуються до 4096 px.
- SVG: inline `<svg>` і SVG-файли стають векторами; стилі з CSS-класів, `currentColor` і спрайти `<use>` вбудовуються.
- Поля форм (`input`, `textarea`, `select`, чекбокси, радіо, `progress`), `canvas`, постери `video`.
- Веб-компоненти з відкритим Shadow DOM і `<slot>`; анімації доводяться до кінцевого стану.

## Обмеження

- **Шрифти** мають бути доступні у Figma. Якщо шрифту немає, використовується найближчий доступний (за замовчуванням Inter) — про це з'явиться попередження.
- Повороти / масштабування (`transform`) передаються як обмежувальна рамка, без повороту шару.
- Таблиці переносяться як фрейми з абсолютним позиціюванням; `clip-path` і маски ігноруються.
- Ресурси з інших доменів завантажуються лише з CORS (або через CORS-проксі). Завантаження сторінки за URL з більшості сайтів потребує проксі — простіше зберегти сторінку як `.html` (з базовим URL).
- Справа-наліво (RTL) текст підтримується обмежено.

## Розробка

```bash
npm install
npm run build       # dist/code.js + dist/ui.html
npm run watch       # перезбірка при змінах
npm run typecheck
npm test            # наскрізний тест без Figma (Playwright + Chromium)
```

### Структура

```
src/
  shared/types.ts     контракт даних між знімачем і основним потоком
  capture/            виконується в iframe з HTML: обхід DOM, текст, CSS, зображення, SVG, псевдоелементи, слайди
  ui/                 інтерфейс плагіна; вбудовує знімач в iframe попереднього перегляду
  main/               основний потік Figma: шрифти, створення вузлів, Auto Layout
test/
  mock-figma.js       мок Figma Plugin API, що «малює» вузли в DOM
  run.mjs             рендерить оригінал і результат плагіна, порівнює скриншоти попіксельно
  fixtures/           складні сторінки для тестів (текст, макет, веб-компоненти)
  decks/              тестові презентації (дек у стилі Claude, scroll-дек, reveal.js)
  decks.mjs           порівнює кожен слайд, показаний самим деком, з фреймом, створеним плагіном
examples/demo.html    демонстраційна сторінка
```

`npm test` запускає справжні `dist/ui.html` і `dist/code.js` у Chromium проти мок-API Figma, відтворює створені шари як DOM і порівнює скриншот з оригінальною сторінкою (`test/out/*.diff.png`). Опції: `--width=390`, `--paragraph`, `--autolayout`, `--flatten`.
